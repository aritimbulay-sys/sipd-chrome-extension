Pengaturan Sinkronisasi ke Server (NAS)

Agar data dari ekstensi langsung masuk ke aplikasi web di NAS tanpa impor JSON, aktifkan sinkronisasi dan isi alamat server.

Catatan: server harus dapat dijangkau dari browser ini. Di browser NAS gunakan http://localhost:8090 atau http://192.168.110.160:8090.
